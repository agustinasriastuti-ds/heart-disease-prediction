# ❤️ Heart Disease Prediction

A machine learning project to predict the likelihood of heart disease based on patient health-related features.

## 📌 Project Overview

Heart disease is one of the major health conditions that can affect individuals across different age groups. Data analysis and machine learning can be used to identify patterns in health-related data and develop predictive models.

This project focuses on building a machine learning model to predict whether a patient is likely to have heart disease based on the available features in the dataset.

The project was developed using **Python** in **Google Colab**.

## 🎯 Objectives

* Explore and understand the heart disease dataset.
* Perform data preprocessing and data cleaning.
* Analyze relationships between features and heart disease.
* Build a machine learning classification model.
* Evaluate the model's performance using appropriate evaluation metrics.
* Identify the model's ability to classify patients based on the available data.

## 📊 Dataset

The dataset contains patient-related health and clinical features that can be used to predict heart disease.

The target variable represents the presence or absence of heart disease.

### Main Process

1. Data loading
